# BAMBINO KIDS FASHION | بامبينو كيدز للأزياء الراقية 🌸

متجر إلكتروني متكامل وعصري لأزياء الأطفال والمواليد، مصمم بأحدث معايير الويب المتجاوبة والجمالية باللغة العربية (RTL)، ومجهز بلوحة تحكم تفاعلية متكاملة وخفيفة لإدارة المنتجات والإعدادات والطلبات المباشرة عبر واتساب.

---

## 🌟 مميزات المتجر الرئيسية

1. **تصميم وهوية لونية فاخرة:**
   - متوافق تماماً مع الهوية الأصلية (`entejsites.com/demo-kids-fashion/`) بدرجات الوردي/المرجاني والأحمر الخفيف الناعم (`#e11d48`, `#ff6b81`, `#fee2e2`, `#fff1f2`).
   - خط **Tajawal** العربي الأصيل بدعم كامل لجميع مقاسات الشاشات والجوالات.

2. **هيكلية صفحات متكاملة Multi-Page:**
   - **الرئيسية (`index.html`):** شريط إعلانات متحرك، هيدر ذكي لاصق، سلايدر العروض الكبرى، ميزات المتجر، شبكة التصنيفات، شريط الخصومات الخاطفة (Flash Deals) مع عداد تنازلي حي، شبكة المنتجات مع فلترة الأقسام بنقرة واحدة، نادي أمهات بامبينو، والفوتر الشامل.
   - **المتجر والكاتالوج (`shop.html`):** تصفح المنتجات مع شريط جانبي متقدم للفلترة حسب القسم، نطاق السعر، الترتيب (الأرخص، الأغلى، الأكثر طلباً، الأعلى تقييماً)، وبحث حي بالاسم.
   - **صفحة تفاصيل المنتج (`product.html`):** استعراض صور المنتج بمعرض تفاعلي، المقاسات، عداد الكميات، زر إضافة للسلة، وزر **طلب فوري عبر واتساب**.
   - **من نحن (`about.html`):** قصة العلامة التجارية ومعايير جودة القطن العضوي 100%.
   - **اتصل بنا (`contact.html`):** قنوات التواصل المباشر ونموذج إرسال رسالة تفاعلي يرسل مباشرة للواتساب.
   - **سياسة الخصوصية (`privacy.html`):** بنود حماية بيانات العملاء وحقوق الخصوصية.
   - **الشروط والأحكام (`terms.html`):** سياسة الطلب، الشحن السريع لكافة مدن المملكة، والاستبدال والاسترجاع.

3. **سلة مشتريات منبثقة وطلب عبر واتساب:**
   - سلة جانبية تفاعلية (Slide-Out Cart Drawer) تظهر عند إضافة أي منتج.
   - نافذة إتمام الطلب (Checkout Modal) تجمع الاسم، رقم الجوال، المدينة، والعنوان وتنشئ رسالة منسقة ومرتبة بالكامل ترسل تلقائياً إلى واتساب المتجر بنقرة زر واحدة.

4. **لوحة تحكم خفيفة للمتجر (`/admin/index.html`):**
   - تسجيل دخول آمن برمز PIN (الافتراضي: `1234`).
   - إحصائيات عامة للمتجر (إجمالي القطع، الأقسام، متوسط الأسعار).
   - إدارة كاملة للمنتجات (إضافة منتج جديد، تعديل الأسعار، تغيير الصور، المقاسات، الشارات، وحذف المنتجات).
   - إعدادات المتجر (شريط الإعلانات، رقم الواتساب، رقم الهاتف، البريد، العنوان، العملة).
   - تصدير واستيراد المنتجات بملف JSON بنقرة واحدة للنسخ الاحتياطي.
   - حفظ فوري ومزامنة مباشرة مع واجهة المتجر عبر `localStorage`.

---

## 🚀 تشغيل وتصفح المتجر محلياً

يمكن فتح أي صفحة مباشرة في المتصفح أو تشغيل سيرفر محلي خفيف:
```bash
# تشغيل سيرفر محلي
python -m http.server 8080
```
ثم فتح: `http://localhost:8080/index.html` أو `http://localhost:8080/admin/index.html`.
